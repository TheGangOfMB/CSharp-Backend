## Git

**В: Чем `git reset --hard` отличается от `git revert`? Что использовать, если коммит уже на сервере?**
Мой ответ (18.10): «revert — потому что у нас нет этого коммита, не сможем синхронизироваться или всё поломается из-за несостыковки».
Оценка: **2/3**. Выбор верный, суть уловлена, но со второй попытки и без ключевых слов: reset *переписывает историю* (нужен `push --force`, ломает чужие ветки), revert *добавляет новый коммит* с обратными изменениями.

## Занятие 19.10.2026 (вторая часть)

**В: Коммит с багом уже запушен, коллеги на нём работают. `reset --hard` или `revert`?** (повтор)
Мой ответ: «revert, мы не удаляем файл, а исправляем, коллеги подтянут».
Оценка: **2/3**. Выбор верный, сам. Но «reset удаляет файл» — неверно: reset убирает *коммит из истории*, нужен `push --force`.

**В: Почему `orders[0].Amount = 5` для `List<struct>` не компилируется, а для массива `arr[0].Amount = 5` работает?** (повтор)
Мой ответ: три строки «достать → изменить → положить» написал верно; причина — «присваиваем временное значение»; про массив — «массив ссылочный, меняем напрямую в ячейке».
Оценка: **1/3**. Код верный, но объяснение размытое, а «массив ссылочный» — не причина (List тоже ссылочный). Правильно: индексатор List — метод `get`, возвращает копию; элемент массива — переменная, доступ напрямую.

**В: `o.Amount = 0; o = new Order{777};` внутри метода без `ref` — что увидит вызывающий?** (повтор)
Мой ответ: «777», потом «100».
Оценка: **0/3**. Правильно 0: первая строка меняет общий объект, вторая — только локальную переменную. Повторить.

**В: Где хранится struct?**
Мой ответ: локальная — в стеке, хранит само значение (верно после подсказки про `new`); поле-struct в классе — «в куче как отдельный объект».
Оценка: **1/3**. Миф «new → куча» и «отдельный объект». Правильно: struct хранится там, где объявлен; поле — inline внутри объекта.

**В: Передача struct в метод с `ref` и без; `ref` для ссылочного типа (`o = new ...` внутри).**
Мой ответ: struct 100 / 90 — верно с причиной. Class с `ref` — сначала «100», после наводящего вопроса — 777, верно.
Оценка: **2/3**. Struct — уверенно. Для class с `ref` — со второй попытки; «переменная внутри класса» вместо «переменная вызывающего кода».

**В: Что значит `up to date with 'origin/main'`, если коллега только что запушил?**
Мой ответ: «status в сеть не ходит, смотрит локально».
Оценка: **2/3**. Суть верная, без термина: `origin/main` — локальная копия состояния сервера, обновляется `fetch/pull/push`.
