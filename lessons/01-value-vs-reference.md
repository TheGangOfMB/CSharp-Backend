1) 
Struct: b = a
	"b" получает копию значения "a"
Class: b = a
	"b" получает ссылка на область памяти объекта "a"

Потому, что в первом случает переменная копирует значение и присваивает себе, а во втором она лишь получает ссылку, путь по которому можно найти значение другой переменной и при изменении значения:

Struct:
	a = 100;
	b = a;
	a = 50;

	то вывод будет: а = 50, и b = 100

Class:
	a = 100;
	b = a;
	a = 50;

	то вывод будет: а = 50, и b = 50
