# Задача 02 — Заказы: struct, class, ref, string

Тема: типы значений и ссылочные (закрепление). Время: ~40 минут.
Код пишешь сам. Явный `Main`, без `namespace std`. Подсказки по синтаксису — только если застрял больше 5 минут.

## Подготовка

Из папки `tasks/` создай консольный проект `02-orders` (как в задаче 01).

## Правило

**Перед каждым запуском** пиши прогноз комментарием рядом с `Console.WriteLine`:
```csharp
Console.WriteLine(order.Total.Amount); // прогноз: 900, потому что ...
```
Потом запускаешь и сравниваешь. Если прогноз не совпал — не стирай, допиши `// факт: ..., ошибся, потому что ...`.

## Шаги

### 1. Типы
- `struct Money` — поля `decimal Amount`, `string Currency`.
- `class Order` — поля `int Id`, `Money Total`, `string Status`.

### 2. Скидка
Метод `static void ApplyDiscount(Order order, decimal percent)` — уменьшает `order.Total.Amount` на процент.
Создай заказ на 1000 RUB, примени скидку 10%, выведи сумму.

### 3. Ловушка со свойством
Поменяй в `Order` поле `Total` на **свойство** `public Money Total { get; set; }`.
Скомпилируй. Что сломалось и почему? Почини, не возвращая поле. Объясни в комментарии.

### 4. Подмена заказа
- `static void Replace(Order order)` — внутри `order = new Order { ... Amount = 1 }`.
- `static void ReplaceRef(ref Order order)` — то же самое, но с `ref`.
Вызови оба для одного заказа, прогноз перед каждым выводом.

### 5. Список платежей
`List<Money> payments` из трёх платежей. Увеличь сумму **второго** платежа на 50. Потом сделай то же самое с массивом `Money[]` — одной строкой.

### 6. Статусы и отчёт
- Статус меняется так: `order.Status = order.Status.ToUpper();` — объясни в комментарии, почему исходная строка `"paid"` не изменилась, а `Status` поменялся.
- Сравни `string s1 = "paid"; string s2 = "PA".ToLower() + "id";` через `==`. Прогноз: `true` или `false`? Почему (ведь это разные объекты)?
- Собери строку-отчёт `"1,2,3,...,1000"` из id заказов 1..1000 через `StringBuilder`.
