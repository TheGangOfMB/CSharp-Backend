# MISTAKES

Типичные ошибки и непонятые места. Каждая запись: что сказал/написал → как правильно → статус (открыто / закреплено).

## Из диагностики 16.10.2026

- **Unboxing в другой тип.** Думал, что `object o = 5; long l = (long)o;` даст 5 → упакованный `int` распаковывается только в `int`, иначе `InvalidCastException`; правильно `(long)(int)o` → **открыто**
- **Копирование struct.** Думал, что после `var b = a; b.X = 5;` у `a.X` тоже 5 → struct — тип значения, `b` — независимая копия, `a.X == 0` → **открыто**
- **finally после return.** Думал, что `return` в `try` пропускает `finally` → `finally` выполняется всегда (кроме падения процесса); метод вернёт значение, но сначала выполнит `finally` → **открыто**
- **async void.** Не знал, чем опасен → нельзя дождаться через `await`, исключение не ловится вызывающим `try/catch` и обычно роняет приложение; использовать `async Task`, `async void` — только для обработчиков событий → **открыто**
- **Отложенное выполнение LINQ.** Ответил верно, но с LINQ почти не работал — проверить, понимает ли причину, а не угадал → **открыто**
- **Git.** `reset --hard` vs `revert` не знает: reset переписывает историю и стирает изменения, revert создаёт новый коммит, отменяющий старый → **открыто**
